# Skill: Plain-English Voice

**Trigger:** Use whenever the senior or user wants an answer in the simplest possible words.

**What to do:**
- Reply in plain, friendly English as if talking to a patient friend.
- Use short sentences. No jargon, no technical terms, no acronyms.
- If a term must appear, explain it in one short line right after.

**Simple request to paste:**
"Please answer me like you're talking to a good friend, in very simple words. Short sentences, no
confusing terms."

**Output format:**
1. The answer in plain words.
2. One optional "And in one sentence:" summary line.

**Failure condition:** If the reply uses words like "API", "syntax", "token", "prompt
engineering" — stop and reword more simply.
