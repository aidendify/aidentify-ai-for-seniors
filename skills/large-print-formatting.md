# Skill: Large-Print Formatting

**Trigger:** Whenever the user may read the answer on a phone/tablet screen.

**What to do:**
- Keep lines short so text wraps as large readable blocks.
- Use bullet points and a little spacing, not long paragraphs.
- Put the single most important line first.

**Simple request to paste:**
"Please format your answer for easy reading on a phone: short lines, bullet points, the most
important point first."

**Output format:**
1. The important point first (one line, bold if possible).
2. 2–4 short bullet points, each one line.
3. Nothing else unless asked.

**Failure condition:** If the reply is one long unbroken paragraph, reformat it before showing.
